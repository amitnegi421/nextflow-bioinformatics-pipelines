# DNA-Seq Variant Calling Pipeline (Nextflow DSL2)

An end-to-end DNA sequencing analysis pipeline developed using Nextflow DSL2 for germline variant calling.

## Features

- FastQC
- Fastp
- BWA-MEM Alignment
- Samtools Sorting
- GATK MarkDuplicates
- GATK HaplotypeCaller
- MultiQC Reporting
- Docker Support
- Modular DSL2 Design
